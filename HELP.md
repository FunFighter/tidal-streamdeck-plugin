# Help

## Install

1. Download the `.streamDeckPlugin` file from `dist/`.
2. Double-click it.
3. Restart Stream Deck if the TIDAL category does not appear right away.

## Requirements

- Windows
- TIDAL desktop app
- Stream Deck 6.6+

## Notes

- `Now Playing` handles play/pause.
- `Next` and `Previous` previews work best when TIDAL's queue/history sidebar is visible.
- If preview art is missing, the plugin falls back safely instead of showing a bad black frame.
